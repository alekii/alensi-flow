# Alensi Flow

**Business Workflow & Automation Platform**

Alensi Flow is a configurable workflow automation platform for building and managing business processes with strong governance, traceability, and operational control.

## 🚀 What This Project Demonstrates

- Configurable workflows
- State machines
- Maker-checker
- Approval chains
- Role-based actions
- Task management
- Notifications
- Audit trails
- Scheduled actions
- Event-driven processing
- Workflow versioning

## 🧱 Tech Stack

- N&N
- Java
- Spring
- WhatsApp API

## 📌 Use Cases

Alensi Flow can be used to implement:

- Internal approval and escalation flows
- Multi-step business operations with strict state transitions
- Compliance-driven processes requiring full auditability
- Real-time and scheduled workflow execution
- Event-triggered automation across teams and systems

## ✅ Core Capabilities

### Workflow Configuration

Define and evolve workflows without rewriting core business logic.

### State Machine Engine

Model process states and enforce valid transitions.

### Maker-Checker Controls

Ensure separation of duties for sensitive actions.

### Approval Chains

Support single-level and multi-level approval models.

### Role-Based Actions

Expose actions dynamically based on assigned user roles and permissions.

### Task Management

Create, assign, and track workflow tasks across actors.

### Notifications

Trigger notifications for task assignment, status changes, and escalations.

### Audit Trails

Capture who did what, when, and why for full traceability.

### Scheduled Actions

Run workflow actions on time-based schedules.

### Event-Driven Processing

React to system or external events in near real time.

### Workflow Versioning

Maintain and execute multiple workflow versions safely.

## 🛠️ Getting Started

1. Clone the repository.
2. Configure environment and application properties.
3. Run the Spring application.
4. Define workflows and roles.
5. Start processing business tasks.
